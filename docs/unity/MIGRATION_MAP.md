# Migration map

## REUTILIZAR COMO DATO
Manifiesto, story bible, diálogos, IDs, personajes, armas, eventos narrativos y valores de balance todavía relevantes.

## REINTERPRETAR EN 3D
Layouts, zonas, posiciones, spawns, interactuables, cámaras, iluminación y escalas.

## REESCRIBIR COMPLETAMENTE
Escenas Phaser, física Arcade, render, UI Phaser, input, enemigos, transición, guardado runtime, animaciones, audio runtime y build web.

## NO MIGRAR
Fallbacks legacy, flujo alternativo, hacks de registry, timers de transición, workarounds Phaser, lógica duplicada y pruebas que simulan progreso modificando variables internas.
